# UNSW-Planner
UNSW Planner is a full-stack web application designed to help UNSW students organise and plan their courses across different terms and academic years.

The application allows users to search for existing courses, add courses that are not yet available in the database, and organise them into a personalised study plan for Term 1, Term 2, and Term 3. Each course can include information such as its course code, name, Units of Credit (UOC), and term availability.

A key idea behind the project is to build a growing course database through user contributions. As more courses are added, future users will be able to search and reuse existing course information rather than entering it manually.

This project is also designed as a practical exploration of full-stack development, including frontend development, REST APIs, relational databases, testing, CI/CD, and deployment.
